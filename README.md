# obsidian_clipper_templates
Like many others, I use Obsidian to capture, record and store information with a goal of creating a self-hosted, private repository of files that are relevant to my life. 
I use Obsidian Web Clipper extensively along with iOS shortcuts to extract and structure information from the web into Markdown files that are saved into my Obsidian Vault. If any of these are useful for you, browse this repo.

Inspired from [kepano's repo](https://github.com/kepano/clipper-templates)

Schema-based templates: Extracts page variables using schema.irg JSON-LD
1. [Recipes](https://github.com/suchstance/ss_obsidian/blob/main/clipper_templates/recipes) gets you the cook time and list of ingredients in a clean markdown file
2. [IMDB](https://github.com/suchstance/ss_obsidian/blob/main/clipper_templates/imdb.json) creates a note with movie metadata and a space to add your own rating



Trigger templates from the website name
1. [Board Games](https://github.com/suchstance/ss_obsidian/blob/main/clipper_templates/board-game-bgg.json) captures new games I've played
2. [Goodreads](https://github.com/suchstance/ss_obsidian/blob/main/clipper_templates/goodreads.json) extracts book ratings and tags them to a nested genre taxonomy
3. [Wikipedia](https://github.com/suchstance/ss_obsidian/blob/main/clipper_templates/wikipedia.json) clips the first paragraph of articles I want to save
